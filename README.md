# astrbot_plugin_moewalls

从 [moewalls.com](https://moewalls.com) 搜索并下载动态壁纸（Live Wallpaper）的 AstrBot 插件。

## 功能

- `/搜壁纸 关键词`：自动把中文关键词翻译成英文后搜索动态壁纸，返回带序号的预览图
- `/序号`：下载对应壁纸的完整视频（mp4）并发送到聊天
- `/壁纸帮助`：查看用法

## 安装

在 AstrBot 插件市场搜索 `astrbot_plugin_moewalls` 安装，或把本仓库目录放到 AstrBot 的 `data/plugins/` 下。

依赖 `aiohttp`、`Pillow`，AstrBot 会根据 `requirements.txt` 自动安装。

## 指令

| 指令 | 说明 |
| --- | --- |
| `/搜壁纸 关键词` | 搜索动态壁纸，返回带序号的预览图 |
| `/序号` | 下载第 N 个壁纸的视频并发送，例如 `/1` |
| `/壁纸帮助` | 查看用法 |

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 搜索结果数量上限 | 12 | 每次搜索返回的壁纸数量（1~40） |
| 把中文关键词翻译成英文 | 开 | 中文关键词先交给对话模型翻译再搜索 |
| 预览图标题显示中文 | 开 | 预览图里每张壁纸的标题用中文显示 |
| 关键词翻译用的对话模型 ID | 空 | 留空使用 AstrBot 当前默认对话模型 |
| 搜索结果缓存有效期（分钟） | 10 | 过期后需重新搜索才能选号下载 |
| 单个壁纸视频体积上限（MB） | 200 | 超过则取消下载 |
| 网页请求超时（秒） | 30 | 搜索页与详情页请求超时 |
| 视频下载超时（秒） | 300 | 该站视频较大，网络慢时请调大 |
| 预览图每行显示数量 | 4 | 预览图排版列数 |
| 临时视频清理延迟（秒） | 180 | 视频发送成功后延迟删除本地临时文件 |

## 说明

- 壁纸为 mp4 视频，体积常见 10~80MB，首次下载可能较慢，插件会实时显示下载进度
- 若发送大视频失败，可调低「单个壁纸视频体积上限」
- 本插件仅做轻量搜索与单次下载，请遵守目标站点的用户协议，勿用于批量采集或商业化搬运
