# astrbot_plugin_moewalls

**在聊天里一句话找到动态壁纸** —— 从 [moewalls.com](https://moewalls.com) 搜索 Live Wallpaper 并下载发送。

## 简介

`astrbot_plugin_moewalls` 是 AstrBot 的动态壁纸插件。发送 `/搜壁纸 关键词`，插件会把中文关键词翻译成英文到 moewalls.com 搜索，返回一张**带序号、中文标题和视频体积**的预览图；回复 `/序号` 即可把对应的动态壁纸视频下载并发到聊天。

## 使用示例

```
你：/搜壁纸 芙芙
Bot：🔍 正在搜索「芙芙」并获取壁纸信息，请稍候...
Bot：[预览图]
     （已翻译为「Furina」搜索）
     共找到 12 个结果，回复 /序号（1-12）下载对应动态壁纸

你：/4
Bot：🔗 正在获取「水神芙宁娜婚纱动态壁纸」的下载地址...
Bot：⬇️ 正在下载「水神芙宁娜婚纱动态壁纸」（约 76.6MB），请稍候...
Bot：⬇️ 下载中 40%（30.6/76.6 MB）
Bot：✅ 下载完成（76.6MB），正在发送视频...
Bot：[视频]
```

预览图效果：每张壁纸左上角是序号徽标，底部是中文标题与视频体积。

## 功能特性

- 🔍 **中文关键词直接搜**：自动翻译成英文，无需自己想英文词
- 🖼️ **带序号的预览图**：一次看完全部结果，中文标题 + 视频体积一目了然
- 📦 **下载前可预判**：预览图标注实际体积，避免下到几十 MB 才发现
- ⬇️ **实时下载进度**：大文件下载过程中持续反馈，不会「没反应」
- 🧹 **本地零残留**：视频与预览图在发送完成后立即删除（可配置延迟）
- 🛡️ **健壮性**：下载地址编码保护、响应类型与文件头校验，避免把错误页当视频发出

## 安装

**方式一：插件市场**

在 AstrBot 插件市场搜索 `astrbot_plugin_moewalls` 安装。

**方式二：手动安装**

```bash
cd AstrBot/data/plugins
git clone https://github.com/kuaiyidian123/astrbot_plugin_moewalls.git
```

重启 / 重载插件即可。依赖 `aiohttp`、`Pillow`，AstrBot 会根据 `requirements.txt` 自动安装。

## 指令

| 指令 | 说明 |
| --- | --- |
| `/搜壁纸 关键词` | 搜索动态壁纸，返回带序号的预览图 |
| `/序号` | 下载第 N 个壁纸的视频并发送，例如 `/1`；裸数字 `1` 也可 |
| `/壁纸帮助` | 查看用法 |

## 配置

在 AstrBot 后台插件配置页填写。

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 搜索结果数量上限 | 12 | 每次搜索返回的壁纸数量（1~40），数值越大出图越慢 |
| 把中文关键词翻译成英文 | 开 | 中文关键词先交给对话模型翻译再搜索 |
| 预览图标题显示中文 | 开 | 预览图里每张壁纸的标题用中文显示，失败自动回退英文 |
| 预览图显示壁纸体积 | 开 | 预览图标注视频实际大小；体积需逐个探测，会略增搜索耗时 |
| 关键词翻译用的对话模型 ID | 空 | 留空使用 AstrBot 当前默认对话模型 |
| 搜索结果缓存有效期（分钟） | 10 | 过期后需重新搜索才能选号下载 |
| 单个壁纸视频体积上限（MB） | 200 | 超过则取消下载并提示 |
| 网页请求超时（秒） | 30 | 搜索页与详情页请求超时 |
| 视频下载超时（秒） | 300 | 该站视频较大（常见 10~80MB），网络慢时请调大 |
| 预览图每行显示数量 | 4 | 预览图排版列数（2~6） |
| 临时视频清理延迟（秒） | 0 | `0` = 发送完立即删除本地文件；协议端上传慢导致发送失败时可调大 |

> 提示：`把中文关键词翻译成英文`、`预览图标题显示中文` 都依赖 AstrBot 的对话模型，请先确保已配置可用的对话模型。

## 工作原理

便于二次开发，简述插件与目标站点的交互：

1. **搜索** — `GET https://moewalls.com/?s=<英文关键词>`，解析结果页里每个 `article` 块的标题、详情页链接与缩略图
2. **取下载凭证** — `GET <详情页>`，从下载按钮 `<a id="moe-download" data-url="...">` 取出加密 token
3. **下载** — `https://go.moewalls.com/download.php?video=<token>` 直接返回 mp4 视频

由于 token 本身是 URL 编码的（含 `%2F`、`%3D` 等），请求时会用 `yarl.URL(..., encoded=True)` 原样保留编码，避免被二次解码导致地址失效。

## 常见问题

**搜索比较慢？**
体积探测需要逐个请求详情页，12 个结果约多 24 次请求。可关闭「预览图显示壁纸体积」或调小「搜索结果数量上限」。

**视频发送失败？**
多半是体积过大。调低「单个壁纸视频体积上限」，或先选体积较小的壁纸。

**本地会残留文件吗？**
不会。默认「临时视频清理延迟」为 `0`，视频和预览图在发送完成后立即删除，且插件启动时会自动清空临时目录。

**下载提示「下载地址已失效」？**
该壁纸的下载凭证已过期，重新 `/搜壁纸` 后再选号即可。
